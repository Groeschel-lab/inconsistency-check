# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful and constructive. Harassment and discriminatory behavior
are not tolerated.

To report unacceptable behavior, contact the maintainers at
**matthias.groeschel@charite.de**. Reports will be handled
confidentially.
